# 📰 News App

A native Android news application built with Kotlin that delivers real-time news updates through NewsAPI.org. The application allows users to browse the latest headlines, search articles by keyword, save favorite news, and enjoy a seamless reading experience with infinite scrolling.

## ✨ Features

- 📰 Real-time news updates powered by NewsAPI.org
- 🔄 Infinite scrolling for continuous article browsing
- 🔍 Search news articles by keywords or topics
- ⭐ Save and manage favorite articles
- 📈 Top Headlines section featuring trending news
- ⚡ Fast and responsive user experience
- 📱 Clean and intuitive Android interface


### Home Screen
Browse the latest news headlines from various trusted sources.

### Article Detail
Read complete news articles with detailed information and content previews.

### Search News
Search for news articles instantly using keywords or topics of interest.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- NewsAPI Account

### Installation

1. Clone this repository

```bash
git clone https://github.com/shabrinadzakiyah/NewsAppMandiri.git
```

2. Open the project in Android Studio

3. Get your API key from:

https://newsapi.org

4. Add your API key to the project configuration

```kotlin
const val API_KEY = "YOUR_API_KEY"
```

5. Run the application

```bash
Run ▶ app
```
